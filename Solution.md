## Assignment 4.2 — Job Application Form

### 1. Aim

To create a job application form using different HTML input types and form elements.

### 2. Theory

HTML forms are used to collect information from users. The `<form>` element contains different input fields that allow users to enter and submit their details. In this assignment, a job application form was created using HTML form elements.

Different input types were used to collect personal information, including full name, email address, phone number, date of birth, and portfolio URL. Radio buttons were used to select one option, while checkboxes allowed users to select multiple skills. A dropdown list was used to select a qualification or job role, and a `<textarea>` was provided for writing a cover letter.

Labels were added to all fields to make the form easy to understand. The `required` attribute was used for mandatory fields, and the `disabled` attribute was used to demonstrate a field that users cannot edit. The submit button allows users to submit the completed form.

### 3. Objectives

- To understand HTML form elements.
- To use different input types in a form.
- To create radio buttons, checkboxes, and dropdown lists.
- To use labels for form fields.
- To apply the `required` and `disabled` attributes.
- To create a user-friendly job application form.

### 4. Technologies Used

- HTML5: To create the structure of the form.
- CSS3: To style the form and improve its appearance.
- Web Browser: To display and test the form.

### 5. HTML Elements and Attributes Used

- `<form>`: Defines the form.
- `<label>`: Provides a description for each input field.
- `<input>`: Accepts different types of user information.
- `type="date"`: Allows users to select a date of birth.
- `type="url"`: Accepts a portfolio URL.
- `type="radio"`: Allows users to select one option from a group.
- `type="checkbox"`: Allows users to select multiple skills.
- `<select>` and `<option>`: Create a dropdown list.
- `<textarea>`: Accepts a longer cover letter.
- `required`: Makes a field mandatory.
- `disabled`: Prevents users from editing a field.
- `<button type="submit">`: Submits the form.

### 6. Procedure

1. Create an HTML document.
2. Add the `<form>` element.
3. Create fields for name, email, phone, date of birth, and portfolio URL.
4. Add radio buttons for gender or preferred shift.
5. Add checkboxes for skills.
6. Create a dropdown for qualification or job role.
7. Add a textarea for the cover letter.
8. Add labels to every field.
9. Apply the `required` attribute to appropriate fields and include a disabled field.
10. Add a submit button and test the form in a web browser.

### 7. Result

A job application form was created successfully using different HTML input types and form elements. The form includes personal details, radio buttons, checkboxes, a dropdown list, a cover letter field, and a submit button.

### 8. Conclusion

This assignment helped me understand how to create HTML forms using different input types and form controls. I learned how to use labels, required fields, radio buttons, checkboxes, dropdown lists, and disabled fields to create a structured and user-friendly job application form.
